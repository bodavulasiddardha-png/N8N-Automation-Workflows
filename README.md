# N8N-Automation-Workflows 🤖

AI-powered automation workflows built with n8n

## Workflows

### 1. Gmail AI Triage Agent
- Gmail lo new emails auto-detect chestundi
- Claude AI tho classify chestundi
- Telegram lo instant alerts vastaayi
- **Tech:** n8n, Claude API, Gmail, Telegram Bot

### 2. AI Job Match Bot
- JSearch API tho daily jobs fetch chestundi
- Claude AI tho job relevance score chestundi
- Matching jobs Telegram ki send avutaayi
- **Tech:** n8n, Claude API, RapidAPI, Telegram Bot

## Tech Stack
- n8n (Self-hosted)
- Claude AI (Anthropic)
- Telegram Bot API
- Gmail API
- JavaScript
